

# Descubra +Cidades: Design de Aplicativo para o Turismo Regional

Este repositório reúne os artefatos visuais, diagramas e protótipos de alta resolução desenvolvidos no âmbito do Trabalho de Conclusão de Curso (TCC) em Bacharelado em Sistemas de Informação pelo **Instituto Federal do Ceará (IFCE) - Campus Cedro**.

O projeto **Descubra +Cidades** é uma solução de engenharia de usabilidade e IHC (Interação Humano-Computador) desenhada para combater a invisibilidade digital do turismo regional e facilitar o planeamento de viagens em cidades de pequeno porte, tendo como foco prático a região Centro-Sul do Ceará e o município de Várzea Alegre.
